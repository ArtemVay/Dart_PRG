# RPG Битва на Dart
*Консольное приложение, демонстрирующее основы объектно-ориентированного программирования на языке Dart. В проекте реализована пошаговая битва между персонажами разных классов (Воин, Маг, Лучник) с использованием наследования, абстракции и полиморфизма.*

## Запуск
1. Клонировать репозиторий:
   `git clone https://github.com/ArtemVay/Dart_PRG.git`
2. Перейти в папку проекта:
   `cd lab_rpg_fio`
3. Установить зависимости:
   `dart pub get`
4. Запустить программу:
   `dart run`

## Что изучил:
* Научился создавать один общий класс-родитель (`Character`) и делать на его основе других персонажей, чтобы не копировать одни и те же поля (имя, здоровье) в каждый класс
* Понял, что абстрактные классы - это просто шаблон. Нельзя создать просто персонажа, можно создать только конкретного
* Наследники могут менять методы родителя под себя. Например, у Воина атака с учетом меча, а у Мага - с учетом маны.
* Переменная типа `Character` может хранить любого наследника, и программа сама понимает, какой именно метод атаки нужно вызвать.

## Ответы
1. Абстрактный класс - это шаблон для других классов. Напрямую создать объект типа `Character` нельзя, потому что у него есть метод `attack` без реализации. Программа не знает, какой именно урон должен наносить просто персонаж
2. Ключевое слово super нужно, чтобы передать имя и здоровье в родительский класс. Если его убрать, код не скомпилируется, так как родительский класс требует эти данные при создании
3. Метод `attack` в родителе пустой, поэтому мы обязаны написать его с нуля. А метод `takeDamage` в родителе уже имеет код, который отнимает здоровье. Мы переопределяем его в Воине, чтобы сначала учесть броню, а потом через `super.takeDamage` вызвать базовое отнимание здоровья
4. Эта концепция называется полиморфизм. Во Flutter мы постоянно с этим сталкиваемся: метод `build` возвращает тип `Widget`, но на самом деле он может вернуть любого наследника, например, `Text`, `Container` или `ElevatedButton`.
5. Нижнее подчёркивание означает, что переменная приватная. Её нельзя прочитать или изменить из других файлов, доступ к ней есть только внутри класса `Character`.
